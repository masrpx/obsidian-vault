# Max's List Method (ระบบลิสต์คู่แท้)

> เชียร์ให้เขียนลิสต์เพราะว่าคุณจะได้ไม่อยู่กับความรู้สึกของคุณ
> — [[ทำไมต้องเขียนออกมาเป็นลิส]]

## Framework

### ทำไมต้องมีลิสต์?
- เห็นภาพชัดว่าตัวเองต้องการอะไร **จริงๆ**
- ไม่ถูกอารมณ์หลอก (ชอบ ≠ ใช่)
- ตัดสินใจจาก logic ไม่ใช่ feeling
- เป็น filter ที่ชัดเจนตั้งแต่วันแรก

### โครงสร้างลิสต์ (3 ระดับ)
1. **Must Have** — ต้องมี ไม่มีคือ Deal Breaker
2. **Nice to Have** — ขยายความ ทำให้ดียิ่งขึ้น
3. **Bonus** — ไม่มีก็ได้ แต่มีจะสุดยอด

### วิธีใช้
- เขียนก่อน ไม่ใช่เจอแล้วค่อยคิด
- ใช้ตอนพบคนใหม่ เช็คกับลิสต์ทันที
- ถ้าไม่ผ่าน Must Have → จบ ไม่ต้อง "ดูกันไปก่อน"
