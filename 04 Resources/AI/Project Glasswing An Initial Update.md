Anthropic's Project Glasswing (launched April 2026) uses Claude Mythos Preview to find critical software vulnerabilities at unprecedented scale — over 10,000 high/critical-severity bugs found across systemically important software in just one month with ~50 partners. The bottleneck has shifted from finding vulnerabilities to patching and disclosing them fast enough, marking a fundamental inflection point in AI-driven cybersecurity. Cloudflare alone found 2,000 bugs with better-than-human false positive rates; Mozilla found 271 Firefox vulnerabilities (10x more than with the previous model); and Mythos Preview is the first model to solve both UK AISI cyber ranges end-to-end. Anthropic has also scanned 1,000+ open-source projects and found an estimated 6,202+ critical vulnerabilities. This signals that AI offensive cyber capability has crossed a threshold where proactive defense infrastructure must scale rapidly to match.
